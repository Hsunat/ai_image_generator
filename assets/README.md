# Open Ai - react native image generator for prompt 

## How to begin this project 

_Note:_ This project needs the following install to successfully run 

'''

$ node --version
v21.6.2
$ npm --version
10.2.4
$ nvm --version
0.39.7
$ npx --version
10.2.4
'''

1. Checkout this project!

2. Run the following command: npm run web: If done properly this hould open a new web browser with the ai generator, if not open browser and type the following url 
'''

http://localhost:8081/
'''

3. make up a prompt!(the fun part)

4. Wait for your image to be generated.
